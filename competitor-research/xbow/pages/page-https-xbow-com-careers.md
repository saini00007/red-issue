# XBOW Jobs

## Summary
`https://xbow.com/careers` redirects to XBOW's hosted Ashby job board at `jobs.ashbyhq.com/xbowcareers`. The board's static HTML shell renders no content without JavaScript ("You need to enable JavaScript to run this app."), but the page embeds a `window.__appData` JSON blob with the full job-board configuration and live listings. As of the fetch date, XBOW has 8 open roles spanning Marketing, GRC, Legal, Security, and Engineering (Agent Kinetics and Platform teams), almost all fully remote and many open to a wide range of countries. The board's intro copy repeats XBOW's core positioning: building "the world's first autonomous pentester, powered by AI."
