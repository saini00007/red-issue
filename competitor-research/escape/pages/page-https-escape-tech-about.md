# About Escape | AI-Powered Offensive Security Platform

## Summary
Escape's About page tells the company's founding story and mission: offensive security that keeps pace with fast-moving engineering teams, built AI-native from the start. It introduces the leadership team, lists the company's core products (AI pentesting, business-logic-aware DAST, external network pentesting, attack surface management), and highlights investors, advisors, culture pillars, and recent research/resources.

## Full content

### Our Story
"We built Escape because the attack surface keeps expanding and most security teams are left mapping it alone." A single security team covering thousands of developers creates overwhelming conditions; Escape focuses on offensive security that matches engineering speed, built as AI-native from inception.

### Our Mission
"Helping security teams navigate an attack surface that never stops growing." Founded in 2020, after a co-founder witnessed how a single exposed API endangered an entire organization. The platform explores attack surfaces continuously and automatically within engineering workflows — positioned as continuous testing that keeps pace with engineering, not a quarterly scanner.
