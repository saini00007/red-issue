# Escape Research: AI for offensive security

## Summary
Escape's Research page presents the company's applied-research efforts behind its AI-driven offensive security products (AI pentesting, business-logic-aware DAST, external network pentesting, attack surface management). It describes five active in-house research tracks — code-to-cloud correlation, agentic offensive security, AI-powered vulnerability remediation, vision AI authentication, and intelligent asset correlation — and links out to benchmarks, blog posts, a podcast, and an interactive "Pentester vs AI" game. Meta description: "Five active research tracks behind the product: business logic testing, agentic pentesting and code-to-cloud correlation. 3 to 4x more true positives than a bare frontier model. Always developed in-house."

## Full content

### Next-Generation AI for Cybersecurity Research
Escape positions its research as rebuilding offensive and application security from the ground up, with focus areas on business logic testing, agentic pentesting, and code-to-cloud correlation. Stated mission: create AI that "empowers security and engineering teams to work together and create secure software faster."

### Main products/solutions referenced
1. AI Pentesting — continuous AI-powered pentesting that learns business logic and proves exploitability
2. Business-Logic-Aware DAST — in-house, AI-powered DAST for application security at the business logic level
3. External Network Pentesting — continuous testing of internet-reachable assets
4. Attack Surface Management — discovery and validation of modern applications, APIs, and infrastructure exposure

### Five research tracks
1. Code-to-Cloud Security Intelligence — links static code structure to runtime behavior across microservices
2. Agentic Offensive Security — uses reinforcement learning for autonomous security testing
3. AI-Powered Vulnerability Remediation — connects runtime vulnerabilities to source code for faster fixes
4. Vision AI Authentication — automates authentication for dynamic security testing
5. Intelligent Asset Correlation — maps relationships between repositories and deployed APIs
