# Escape: AI-Powered Offensive Security Platform

## Summary
Escape's homepage positions the company as an AI-powered offensive security platform covering attack surface management (ASM), business-logic-aware DAST, AI pentesting, and AI-powered remediation. It emphasizes a six-step security cycle (discover, test, validate, remediate, automate, comply), heavy use of quantified performance claims (coverage, ROI, time savings), and numerous customer testimonials from companies like Arkose Labs, PandaDoc, DataVault, Visma, and Schibsted. The page also links out to security research, blog content, a podcast, and compliance/trust resources.

## Features / claims mentioned
- Attack Surface Management: discover and validate exposure of modern applications, APIs, and infrastructure from code to cloud
- Business-logic-aware DAST: replaces legacy DAST, improves over time, helps remediate real exploitable vulnerabilities
- AI Pentesting: replaces manual pentest and bug bounty programs, scalable solution for complex web security issues
- AI-powered Remediation: AI-assisted remediations with real code suggestions tailored to specific frameworks
- Six-step security cycle: Discover (ASM) → Test (DAST) → Validate (AI Pentest) → Remediate → Automate → Comply
- Business logic testing: workflows, access control, multi-step processes
- Built for modern auth: OAuth, SSO, multi-tenant
- Agentic attack reasoning powered by graph context
- Proof of exploitability with screenshots and execution logs
- Regression testing for bug bounty findings
- Event-based workflows for triage and escalation
- Security gates in CI/CD pipelines
- Support for 20+ compliance frameworks: PCI-DSS, HIPAA, CRA, SOC 2, ISO 27001
- IDOR scanning and multi-tenant testing capabilities (per customer testimonial)
- AI-based authentication and project-scoped permissions reducing onboarding time
- Custom scanning rules per technology (per customer testimonial)
- Cascade: agentic/whitebox pentesting architecture
