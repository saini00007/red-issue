=== CONCLUSION ===
The application accepts JWT tokens with "alg": "none" (no signature verification), allowing an attacker to forge arbitrary tokens with any claims. The forged token with role:"admin" successfully granted access to the admin endpoint /api/v1/admin/users, returning all users' sensitive data (emails, IDs, roles, etc.). This confirms the JWT Algorithm Confusion vulnerability with critical impact - privilege escalation and unauthorized data access.
