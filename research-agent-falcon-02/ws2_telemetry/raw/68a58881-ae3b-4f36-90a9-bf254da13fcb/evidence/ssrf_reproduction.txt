The /api/v1/uploads/fetch-url endpoint accepts a user-controlled 'url' parameter and makes server-side HTTP requests to it. The endpoint successfully fetches content from the OAST domain (oobd01522271a1b.datf6t0hgqag02gk65agnaytj47t1eyph.oast.abhedi.co.in) as evidenced by the 200 status code and returned HTML content. This confirms the SSRF vulnerability.
