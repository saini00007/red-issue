Executive summary

The duck-store e-commerce platform suffers from systemic authentication and authorization failures: three independent JWT algorithm confusion flaws grant full admin takeover, SQL injection in login and product filter enables credential bypass and data exfiltration, two SSRF vectors expose internal infrastructure, and 13 sensitive endpoints lack rate limiting enabling credential stuffing at scale. Combined with mass assignment privilege escalation, IDOR/bolA across orders and testimonials, and missing supply-chain integrity (SRI), the application is critically exposed to account takeover, financial fraud, PII theft, and complete server compromise.

Risk & business impact

The duck-store.escape.tech application suffers from catastrophic authentication and authorization failures that collectively allow full administrative compromise. Three independent JWT algorithm confusion flaws (alg=none) enable any user to forge tokens and escalate to admin privileges across all protected endpoints, while a critical mass assignment vulnerability allows direct role manipulation via profile updates. These are compounded by SQL injection in the login form providing authentication bypass, multiple unauthenticated access points to sensitive data, and broken function-level authorization letting regular users reach admin endpoints. An attacker can chain these to achieve complete account takeover, data exfiltration, and potential business logic abuse such as price manipulation.

Scan effort & capability

Testing was conducted across two phases using 169 autonomous agents and 172 workers executing 12,143 tool invocations spanning 36 unique tools. Coverage included 6,578 targeted HTTP requests via curl, 1,703 sqlmap payloads for injection discovery, 898 out-of-band interaction tests for SSRF/XXE validation, 287 dalfox scans for client-side issues, 15 jwt_tool operations for token analysis, and 17 nuclei template runs. The effort consumed over 1 million tokens and exercised the full attack surface from unauthenticated reconnaissance through authenticated business logic abuse.

ssrf · https://duck-store.escape.tech/api/v1/uploads/import-from-url
Blind SSRF via the import-from-url endpoint lets an attacker force the server to make arbitrary outbound requests, enabling internal network reconnaissance, cloud metadata access, or chained attacks on internal services. The OOB callback confirms the server processes attacker-controlled URLs without validation.

Use a dedicated HTTP client that does not follow redirects to internal addresses.
